# تشريح ESP32 ثلاثي الأبعاد

نموذج تفاعلي ثلاثي الأبعاد للوحة **ESP32 DevKitC** يشرح كل قطعة فيها بلغة بسيطة للمبتدئين.

**عمل الطالب: عبد العزيز فهد الجعيد**
GitHub: [0xazc0000e](https://github.com/0xazc0000e) · تلقرام: [@afjo45](https://t.me/afjo45)

## المحتوى
- نموذج بأبعاد حقيقية بالمليمتر لكل قطعة: الوحدة، المعالج، الذاكرة، الكريستال، الهوائي، منفذ USB، المنظم، الأزرار، والأطراف الـ38.
- جولة تعليمية من 16 خطوة تتبع طريق الكهرباء والبيانات.
- فصل الطبقات ورؤية ما تحت الغطاء المعدني.
- دليل الأطراف: أيها آمن وأيها محجوز.
- قاموس مصطلحات، وثلاث تجارب أولى في Arduino IDE.

## التشغيل
العرض المباشر: https://0xazc0000e.github.io/esp32-3d-teardown/

أو افتح `index.html` في المتصفح.

مبني بـ three.js.
